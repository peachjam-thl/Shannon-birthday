# Shannon 的像素生日掌机 · 第二版

固定的 Switch 造型掌机外壳，中间屏幕显示四个像素游戏页面。翻页、错误提示、宝箱动画、抽卡弹窗和粒子效果都发生在屏幕内。

## 页面流程

1. 解锁画面：标题为 `Happy BIRTHDAY SHANNON!!!`。用户图二在左、图一在右。问题为“你最喜欢的角色是谁？”，精确答案为 `奶蛙`。
2. 在横跨太平洋的像素地图上逐张抽取五张随机且不重复的签卡，支持点击地点重读。对应：呼和浩特＝紫色·自在、上海＝蓝色·冷静、北京＝红色·发财、成都＝绿色·生命、美国湾区＝橙色·热情。美国西部显示在地图右侧。
3. 收下第五张签卡后显示“恭喜集齐五蛙之力，召唤正统奶蛙！！！”弹窗，上方为用户图 6；确认“打开信件”后进入标题为 `LETTER TO SHANNON` 的祝福信，读完后点击“还有一句话”继续。
4. 独立的像素星空结尾页，以大字显示 `HAPPY BIRTHDAY SHANNON!!!`。

星空在网站打开时提前加载。进入结尾页前等待背景图片解码和英文字体就绪，背景与文字随同一页面动画显示；网络未就绪时先保留信件页并显示准备状态。样式、脚本和本次变更的字体引用带版本参数，避免新旧缓存混用，后续修改对应资源时应同步更新版本标记。

每次重新打开或刷新，先显示解锁画面；每次成功输入答案均重置为 0/5。进度只保存在本次页面内存，取消 localStorage 存档，并在成功解锁时移除旧版本存档。回到解锁画面后需要重新回答；在地图、信件和结尾之间翻页则保留当前这一轮。密码是生日小游戏的前端答案。

## 后续填写内容

只修改 `dist/content.js`：

- `cards` 固定五项，`image` 按顺序使用用户图 1–5（紫、蓝、红、绿、橙）；`title` 为自在、冷静、发财、生命、热情，`text` 按用户原稿逐字填写。
- `letter.title`、`letter.text`、`letter.signature` 当前均为空字符串。
- 插图放在 `dist/assets/`，例如 `image: 'assets/card-01.png'`。
- 正文换行使用 `\n`。默认空白区域不显示示例祝福。

地图卡片下方显示两字标题和地点名称，内部 `id` 用于图文对应。地点及摆放位置在 `dist/app.js` 的 `CARD_PLACES` 中；五个定位点以引线连接卡片，避免邻近地点重叠。手机竖屏可左右滑动地图。未抽到的卡显示虚线空位和问号；抽取时在屏幕内显示宝箱摇动，随后卡片弹出，收下后地点卡片落下并亮起。含签文的卡片适当缩小顶部插图区，保留像素字体和下方签文阅读区。

六张奶蛙图片均直接复制用户原始 PNG，SHA-256 一致，不重新生成或修改图像。收藏夹与抽签弹窗共用各自对应图片；图 6 使用 `assets/frog-summoned.png`。

每轮收集满五张后首次进入信件前显示恭喜弹窗；同一轮确认后再次读信不重复显示。新一轮重新启用集齐门槛和恭喜弹窗。右/下或 A 可以确认弹窗，左/上、B、Esc 可以返回收藏夹。

中文内容增加后，运行 `python subset-font.py`，把新增文字加入像素字体子集。需要 Python fontTools；原始像素字体在 `pixel-font-source.woff`。

## 本地预览

在本目录运行：`python -m http.server 8787 --directory dist --bind 127.0.0.1`。
浏览器打开 http://127.0.0.1:8787/ 。无需安装前端依赖或配置数据库。

## 操作

- A：确认；在信件页按 A 可进入星空结尾；B：关闭签卡或返回。
- 左侧方向键：左/上返回上一页，右/下进入下一页；键盘四个方向键使用相同规则。未解锁和未集齐时会保留相应门槛。
- 手柄 Home：回到解锁画面；左手柄 ♪：播放或暂停用户提供的生日歌。暂停后再次点击会续播，翻页和抽卡不中断；页面打开或刷新后不会自动播放。歌曲播完后按钮恢复为播放状态，再次点击从头播放。
- 支持手机竖屏排版与横屏掌机布局。动画遵循减少动态效果偏好。
