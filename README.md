# Shannon 的像素生日掌机 · 第二版

固定的 Switch 造型掌机外壳，中间屏幕显示六个像素游戏页面。翻页、接礼物、吹蜡烛、抽卡弹窗和粒子效果都发生在屏幕内。

## 页面流程

1. 解锁画面：标题为 `Happy BIRTHDAY SHANNON!!!`。用户图二在左、图一在右。问题为“你最喜欢的角色是谁？”，精确答案为 `奶蛙`。
2. 在横跨太平洋的像素地图上逐张抽取五张随机且不重复的签卡，支持点击地点重读。对应：呼和浩特＝紫色·自在、上海＝蓝色·冷静、北京＝红色·发财、成都＝绿色·生命、美国湾区＝橙色·热情。美国西部显示在地图右侧。
3. 收下第五张签卡后显示原奶蛙召唤弹窗，确认“出发接礼物”后进入独立的夕阳花园。礼物雨持续 20 秒，奶蛙可上下左右自由移动、在任意高度接取礼物；无扣分和失败门槛。结束显示“今年的好运，全部接住！”，才可打开信件。
4. 标题为 `LETTER TO SHANNON` 的祝福信，正文继续等待用户提供；读完后点击“许一个愿望”。
5. 在暖灯生日小屋中填写一个愿望，也可留空。双层像素蛋糕带草莓、奶油花、淋面和明暗层次。点击“吹灭蜡烛”或按 A，五根蜡烛依次熄灭，才可点击“点亮星空”。愿望只在本次页面内存显示，不上传或保存。
6. 独立的像素星空结尾页，以大字显示 `HAPPY BIRTHDAY SHANNON!!!`。

星空在网站打开时提前加载。进入结尾页前等待背景图片解码和英文字体就绪，背景与文字随同一页面动画显示；网络未就绪时先保留信件页并显示准备状态。样式、脚本和本次变更的字体引用带版本参数，避免新旧缓存混用，后续修改对应资源时应同步更新版本标记。

每次重新打开或刷新，先显示解锁画面；每次成功输入答案均重置签卡、礼物雨和许愿状态。进度只保存在本次页面内存，取消 localStorage 存档，并在成功解锁时移除旧版本存档。回到解锁画面后需要重新回答；六页之间翻页则保留当前这一轮。密码是生日小游戏的前端答案。

## 后续填写内容

只修改 `dist/content.js`：

- `cards` 固定五项，`image` 按顺序使用用户图 1–5（紫、蓝、红、绿、橙）；`title` 为自在、冷静、发财、生命、热情，`text` 按用户原稿逐字填写。
- `letter.title`、`letter.text`、`letter.signature` 当前均为空字符串。
- 插图放在 `dist/assets/`，例如 `image: 'assets/card-01.png'`。
- 正文换行使用 `\n`。默认空白区域不显示示例祝福。

已抽到的地图卡片显示两字标题和地点名称；未抽到的卡片只显示问号与地点，鼠标提示及朗读标签也不提前透露签名。内部 `id` 用于图文对应。地点及摆放位置在 `dist/app.js` 的 `CARD_PLACES` 中；五个定位点以引线连接卡片，避免邻近地点重叠。美国上方可见区域补充了加拿大，分别以浅绿色与蓝绿色区分。手机竖屏可左右滑动地图。抽取时在屏幕内显示宝箱摇动，随后卡片弹出，收下后地点卡片落下并亮起。

六张奶蛙图片均直接复制用户原始 PNG，SHA-256 一致，不重新生成或修改图像。收藏夹与抽签弹窗共用各自对应图片；图 6 使用 `assets/frog-summoned.png`。

每轮收集满五张后首次进入信件前显示恭喜弹窗；同一轮确认后再次读信不重复显示。新一轮重新启用集齐门槛和恭喜弹窗。右/下或 A 可以确认弹窗，左/上、B、Esc 可以返回收藏夹。

中文内容增加后，运行 `python subset-font.py`，把新增文字加入像素字体子集。需要 Python fontTools；原始像素字体在 `pixel-font-source.woff`。

## 本地预览

在本目录运行：`python -m http.server 8787 --directory dist --bind 127.0.0.1`。
浏览器打开 http://127.0.0.1:8787/ 。无需安装前端依赖或配置数据库。

## 操作

- A：确认；在礼物页开始/暂停/继续，在许愿页吹蜡烛；B：暂停游戏、关闭签卡或返回。
- 普通页面方向键左/上返回，右/下继续。礼物雨运行时，四个方向键、屏幕四向按钮及自由拖动都支持二维移动；键盘短按立即移动、按住持续移动，碰撞区域跟随奶蛙的横纵坐标。倒计时按实际经过时间计算。切走页面、窗口失焦或浏览器转到后台时自动暂停，可回来继续。
- 未解锁、未集齐签卡、礼物雨未结束或蜡烛未熄灭时，相应后续页面保持门槛。六个页面导航点随进度更新。
- 手柄 Home：回到解锁画面；左手柄 ♪：播放或暂停用户提供的生日歌。暂停后再次点击会续播，翻页和抽卡不中断；页面打开或刷新后不会自动播放。歌曲播完后按钮恢复为播放状态，再次点击从头播放。
- 支持手机竖屏排版与横屏掌机布局。动画遵循减少动态效果偏好。

手机布局以 iPhone 15 Pro 的 393 × 852 CSS 像素视口为基准，独立样式位于 `dist/mobile.css`。使用稳定的小视口高度 `svh` 和四边安全区，兼容 Safari 地址栏展开后的短视口。竖屏屏幕加宽、主要操作按钮高 44px、输入框字号 16px，避免 iOS 聚焦输入框时自动放大；解锁成功先收起输入焦点。地图保留横向滑动，弹卡与信件正文可独立滚动，小游戏四向触控按钮完整显示。
